# 1.3.0 application update

Imports original-project PDF, font and audio repairs; retains platform adapters,
UI motion, worker cancellation and shutdown behavior. Includes addon source and
an Addon verification tool with seven local synthetic checks.
The addon API still configures no document channels. No claim of live ATS
recovery, universal format support or production readiness is made.
The prior 166-case source audit is distinct from application acceptance tests.
WebM uses MOVIE/TITLE with the tested parser, not guaranteed lowercase title.
Original payload strings are retained. No personal resume or signing key ships.
Windows core remains native-compiled; addon modules use packaged bytecode.
Neither artifact is impossible to reverse engineer.
